# Permutation Sorting Puzzles

Die Zahlen 1 bis n² werden in ein n×n-Feld eingetragen. Jede Zeile und Spalte hat ein Label: A (aufsteigend) oder D (absteigend). Zeilen werden von links nach rechts gelesen, Spalten von oben nach unten.

Seite: https://inkmptnz.github.io/permutation-puzzle/

Übungspuzzles direkt öffnen: `#puzzle-1`, `#puzzle-2`

## Lokal

```bash
python3 -m http.server 8000
```

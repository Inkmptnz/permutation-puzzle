Permutation Sorting Puzzles

Zusammenfassung

Auf einem Spielfeld der Größe n × n werden die Zahlen 1 bis n2 eingetragen. Jede Zeile und jede Spalte trägt ein Label: A verlangt aufsteigende, D absteigende Zahlen. Zeilen werden von links nach rechts gelesen, Spalten von oben nach unten. Ein Klick auf ein Label kehrt seine Richtung um.
